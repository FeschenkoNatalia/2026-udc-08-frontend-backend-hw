# Докази до Tasks A, B, C

Тека містить знятий вивід і короткий опис методики та результатів. Команди й прогони виконувались проти
застосунку на `http://localhost:3080` (`cd app && npm run dev`) і проти
тестового набору (`cd app && npm test`).

| Файл | Що доводить |
|---|---|
| [task-a-ui.md](./task-a-ui.md) | Task A — UI архівування перевірено в браузері: дерево доступності, порядок табуляції, розміри цілей, контраст, скріншоти |
| [task-b-api.md](./task-b-api.md) | Task B — колонка, міграція, ендпоінт, серверна валідація, форма відповіді |
| [task-c-authorization.md](./task-c-authorization.md) | Task C — відтворення засіяного витоку, правка, тест, що червоніє до правки, прохід усіма маршрутами |
| [screenshots/](./screenshots) | Знято з поточного коду. **01–09** — стани інтерфейсу з реального Chrome (Task A); **10–18** — справжній вивід `curl` і `vitest`, відрендерений як термінал (Tasks B, C); **task-e-*** — артборди Claude Design (Task E) |

**Інструменти перевірки.** Браузер керувався через Chrome DevTools Protocol —
без нових залежностей: Node 24 має вбудований `WebSocket`, тож клієнт CDP
вмістився у ~90 рядків. Це важливо для `AGENTS.md`: жодного бандлера,
жодного фреймворку, жодних нових пакетів у `package.json`.

**Поточний стан:** 89 тестів зелені (9 засіяних без змін), сідові
дані на місці — Оля (id 1) з двома нотатками, Тарас (id 2) з однією.
